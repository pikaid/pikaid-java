Java conformance suite.

The `pikaid-v1` filename is historical. The pikaid identifier format is
immutable and unversioned; specification revision `1.0.4` is normative at
<https://github.com/pikaid/pikaid-specs/tree/v1.0.4>.

The vector file is test data only. The library itself has no dependency on the
PHP implementation.
